# Official code-set sources

All assets in this folder are generated by `tool/build_code_assets.py` from
public files published by the US Centers for Medicare and Medicaid Services
(CMS). Files were downloaded on 2026-10-16 into
`%TEMP%/solis_codesets` (not committed). Rebuild with:

    python -I tool/build_code_assets.py            # downloads if missing
    python -I tool/build_code_assets.py --offline  # reuse existing downloads

Format of every asset: gzip-compressed UTF-8, tab separated, no header row.

## ICD-10-CM (diagnoses)

Two fiscal-year editions are bundled, because a visit must be coded with the
edition in effect on its date of service. FY N covers October 1 of year N-1
through September 30 of year N. The Dart API picks the edition with
`IcdCatalog.forDate(dos)` / `IcdIndex.forDate(dos)`; `load()` returns the
edition for today (FY2027 as of 2026-10-16).

Page for both: https://www.cms.gov/medicare/coding-billing/icd-10-codes

FY2027 (dates of service 2026-10-01 through 2027-09-30), current:
- Code descriptions: https://www.cms.gov/files/zip/2027-code-descriptions-tabular-order.zip
  (member `icd10cm_order_2027.txt`; 98,403 rows, 74,879 valid for HIPAA
  submission).
- Alphabetic Index: https://www.cms.gov/files/zip/2027-code-tables-tabular-index.zip
  (member `icd10cm_index_2027.xml`).
- Changes against FY2026 (computed from the two order files): 238 codes
  added (for example C78.31, D69.11, I42.00, I42.01, I42.09), 21 deleted (for
  example S23.420A, T52.8X1A), and 15 codes that were billable in FY2026 are
  headers in FY2027 (for example I42.0, I42.8, I49.8, D69.1, M72.2, Z87.890).

FY2026, April 1, 2026 update (dates of service 2025-10-01 through
2026-09-30; the April update made no code changes to the October 2025 list):
- Code descriptions: https://www.cms.gov/files/zip/april-1-2026-code-descriptions-tabular-order.zip
  (member `icd10cm_order_2026.txt`; 98,186 rows, 74,719 valid for HIPAA
  submission, 23,467 headers).
- Alphabetic Index: https://www.cms.gov/files/zip/april-1-2026-code-tables-tabular-index.zip
  (member `icd10cm_index_2026.xml`, Index to Diseases and Injuries).

Assets (one pair per edition, FY = 2026 or 2027):
- `icd10cm_FY.tsv.gz`: code with dot, billable flag (1 valid for submission,
  0 header), official long description.
- `icd10cm_index_FY.tsv.gz`: index path (main term and subterms joined by
  `|`, nonessential modifiers removed) and the code it resolves to. Only
  entries with a code that exists in the same edition's tabular list are kept
  (63,138 rows for FY2026, 63,258 for FY2027); `see` and `see also` cross
  references are dropped. A trailing `-` (code needs more characters) is
  removed, so some index codes are headers.

To add a new edition: add its two zips to `SOURCES` and its year to
`ICD_EDITIONS` in the build script, and to `IcdEditions.available` in
`lib/services/codesets/code_set_loader.dart`.

## HCPCS Level II

- Release: October 2026 alpha-numeric HCPCS file (file date 2026-09-23).
- Page: https://www.cms.gov/medicare/coding-billing/healthcare-common-procedure-system/quarterly-update
- File: https://www.cms.gov/files/zip/october-2026-alpha-numeric-hcpcs-file.zip
  (member `HCPC2026_OCT_ANWEB_09232026.txt`, layout `HCPC2026_recordlayout.txt`).
- Asset `hcpcs.tsv.gz`: code, short description, long description. Only
  Level II codes (letter plus four digits) without a termination date before
  2026-10-01 are kept (7,448 codes). Modifier records are not included.

## Medicare Physician Fee Schedule 2026

- Release: RVU26D, October 2026 release, updated 08/26/2026.
- Page: https://www.cms.gov/medicare/payment/fee-schedules/physician/pfs-relative-value-files/rvu26d
- File: https://www.cms.gov/files/zip/rvu26d-updated-08-26-2026.zip
  (member `PPRRVU2026_Oct_nonQPP.csv`).
- Asset `pfs_rvu.tsv.gz`: code, status indicator, non-facility total RVU,
  facility total RVU, global days, work RVU, PC/TC indicator and bilateral
  surgery indicator (columns 3, 11, 12, 14, 5, 13 and 19 of the CSV). The last
  three drive NCCI-EM-03 (E/M with an XXX procedure) and NCCI-MUE-03
  (modifier 50 and units). Rows with a modifier (26, TC, 53 and so on) are
  dropped. CPT descriptors are AMA-copyrighted and are NOT included. Rebuild
  only this file with `python -I tool/build_code_assets.py --offline --pfs-only`.
- RVUs are identical in the nonQPP and QPP files; only the conversion factor
  differs.

Conversion factors (CY 2026):
- 33.4009 dollars per RVU for clinicians who are not qualifying APM
  participants. Exact value from the CONV FACTOR column of
  `PPRRVU2026_Oct_nonQPP.csv` (RVU26D).
- 33.5675 dollars per RVU for qualifying APM participants. Exact value from
  the CONV FACTOR column of `PPRRVU2026_Oct_QPP.csv` (RVU26D).
- Both are set by the CY 2026 Medicare Physician Fee Schedule final rule,
  CMS-1832-F. CMS fact sheet, October 31, 2025 (rounded values $33.40 and
  $33.57):
  https://www.cms.gov/newsroom/fact-sheets/calendar-year-cy-2026-medicare-physician-fee-schedule-final-rule-cms-1832-f

Amounts computed in the app are national and unadjusted (no GPCI locality
adjustment, no payment policy indicators applied).

## NCCI Medically Unlikely Edits, practitioner services

- Release: 2026 Q4, effective 2026-10-01.
- Page: https://www.cms.gov/medicare/coding-billing/national-correct-coding-initiative-ncci-edits/medicare-ncci-medically-unlikely-edits
- File: https://www.cms.gov/files/zip/medicare-ncci-2026-q4-practitioner-services-mue-table.zip
  (member `MCR_MUE_PractitionerServices_Eff_10-01-2026.csv`).
- Asset `mue_practitioner.tsv.gz`: code, MUE value (max units), MUE
  adjudication indicator (1 line edit, 2 date of service policy, 3 date of
  service clinical). 15,212 rows. Rationale text is not included.

## NCCI procedure-to-procedure edits, practitioner (not bundled)

- Release available: 2026 Q4, version 32.3 (files `ccipra-v323r0-f1` to `f4`).
- Page: https://www.cms.gov/medicare/coding-billing/national-correct-coding-initiative-ncci-edits/medicare-ncci-procedure-procedure-ptp-edits
- Not included: CMS serves the complete PTP tables only after the visitor
  accepts the AMA CPT license agreement on
  `https://www.cms.gov/license/ama?file=...`. Accepting that license is a
  decision for the app owner, so the build did not do it.
- Internal use (current setup): the founder accepted the CMS click-through
  on 2026-10-16. Its terms allow use only inside the organization, so the
  table is built to `local_data/ptp_practitioner.tsv.gz` (git-ignored, not an
  app asset) with `python -I tool/build_code_assets.py --ptp-only`, reading
  the `ccipra-*.zip` files placed in `%TEMP%/solis_codesets/ptp/`. It is used
  by `test/ptp_test.dart` on that computer and by `ClaimScrubber.ptpIssues`
  whenever `ReferenceData.ptp` is set.
- Shipping it in the app requires an AMA CPT distribution license; then
  rebuild with `--ship-ptp`, which writes it to `assets/codes/`, and the app
  loads it at startup.

## Coding-edit lists (from knowledge/rules/)

Built by `python -I tool/build_code_assets.py --knowledge-only` (also part of
a full build) from the files `tool/build_knowledge_base.py` extracts into
`knowledge/rules/`. No download is needed for this step. Each list is
optional: when its asset is missing, `ReferenceData` leaves it null and the
claim checks that use it are skipped.

- `icd10cm_excludes1_2027.tsv.gz` (5,314 notes): where the note sits (a
  code, which covers every code below it, a block range such as `I10-I1A`,
  or a chapter range; `chapter-N` is resolved to the chapter's code range)
  and the excluded reference (code, prefix ending in `-`, or inclusive range
  `A-B`). Source: ICD-10-CM FY2027 Tabular List XML,
  https://www.cms.gov/files/zip/2027-code-tables-tabular-index.zip (member
  `Table and Index/icd10cm_tabular_2027.xml`, `excludes1` notes). Used for
  dates of service from 2026-10-01.
- `icd10cm_excludes1_2026.tsv.gz` (5,310 notes), `icd_7th_2026.tsv.gz` (508
  prefixes) and `icd_notes_2026.tsv.gz` (11,057 note lines): the same lists
  for FY2026 (dates of service through 2026-09-30), parsed with the same code
  from `Table and Index/icd10cm_tabular_2026.xml` in
  https://www.cms.gov/files/zip/april-1-2026-code-tables-tabular-index.zip by
  `python -P tool/build_code_assets.py --tabular-only` (part of a full build;
  the extracts are not kept in knowledge/).
- `icd_7th_2027.tsv.gz` (508 prefixes): category or subcategory prefix and
  its allowed 7th characters as `A=initial encounter|D=...`. Source: the same
  Tabular XML (`sevenChrDef` notes).
- `mce_v44.tsv.gz` (8 lists): list name, age min, age max, comma-separated
  codes. Lists: `age_newborn` (42 codes, age 0), `age_pediatric` (126, 0-17),
  `age_maternity` (2,587, 9-64), `age_adult` (857, 15-124),
  `manifestation_not_principal` (422), `unacceptable_principal` (2,667,
  inpatient), `unacceptable_principal_requires_secondary` (Z51.89) and
  `unspecified_with_laterality_available` (3,476, edit 20, used by ICD-LAT-02).
  Source: Definitions of Medicare Code Edits v44.0 (FY2027, effective
  2026-10-01), https://www.cms.gov/files/zip/fy2027-fr-definition-mce-v44.zip.
- `ncci_addon.tsv.gz` (723 add-on codes): add-on code, AOC type (1 listed
  primaries only, 2 contractor-defined primaries, 3 listed plus
  contractor-defined) and comma-separated primary codes (the `CCCCC`
  placeholder of type 2 rows is dropped). Source: Medicare NCCI add-on code
  edits effective 2026-10-01,
  https://www.cms.gov/files/zip/add-code-edits-medicare-effective-10012026.zip.
  Codes are bare HCPCS/CPT numbers as CMS publishes them; no descriptors.

## Knowledge base for explanations and Tabular notes

Built by the same `--knowledge-only` step. All three are public domain US
government text (CMS and NCHS); no CPT descriptors and no NCCI manual text
(the manual quotes CPT descriptors, so only its chapter and section titles
are cited).

- `icd_notes_2027.tsv.gz` (11,111 note lines, 168 KB): node (code, category,
  block range or chapter range), kind (`E1` Excludes1, `E2` Excludes2, `CF`
  code first, `UA` use additional code, `CA` code also, `N` note), the note
  text and the codes it names (comma separated). Inclusion terms are not
  bundled. Source: `knowledge/rules/icd10cm_code_notes_2027.jsonl`, extracted
  from the ICD-10-CM FY2027 Tabular List XML
  (https://www.cms.gov/files/zip/2027-code-tables-tabular-index.zip). Drives
  ICD-CODEFIRST-01, ICD-MANIF-01, ICD-USEADD-01, ICD-CODEALSO-01, CH4-DM-01,
  the coder's code-first ordering, and the "Coding notes" shown for each
  diagnosis in the claim tab.
- `guidelines_fy2027.tsv.gz` (492 sections, 70 KB): section id (for example
  `IV.H`), heading, text (paragraphs joined by a literal `\n`). Source:
  `knowledge/guidelines/*.md`, extracted from the ICD-10-CM Official
  Guidelines for Coding and Reporting FY2027,
  https://www.cms.gov/files/document/fy-2027-icd-10-cm-coding-guidelines.pdf.
  Shown in the "Why" sheet of each claim check.
- `rule_catalog.tsv.gz` (81 rules, 9 KB): id, title, severity, short
  citation, all citations, plain-English rule, cited guideline sections. The
  63 coding rules come from `knowledge/rules/rule_catalog.json`; 18 `CLAIM-`
  rules (claim form data: CMS-1500 items, Medicare manual sections) are
  defined in `APP_RULES` of the build script. The same step writes
  `lib/services/coding/rule_citations.g.dart`, the id to citation map every
  `ClaimIssue` carries.
